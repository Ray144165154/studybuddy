    这是本机数据目录，不是项目源码目录。换电脑需复制整个数据目录；API Key 需重新填写。

    问你的教材

    先导入一本 PDF，然后随便问。配置模型后可提问；点击回答中的引用，核对教材原文与 PDF 页序。

    学习记忆

    怎么用

    1. 接入模型：右上角「设置」→ 点 DeepSeek（或 OpenAI / 本地 Ollama）→ 粘贴 API Key。 Key 只存在内存里，重启需要重填。
    2. 导入教材：左侧「导入 PDF 教材」。支持中英文；扫描版（整页是图片）需要先做 OCR， 否则会提示「没有可提取的文字」。
    3. 开始提问：底部输入问题，Enter 发送。回答里的 [1] 可以点， 会跳到下面的来源（书名 + 页码 + 小节）。

    常见问题

    回答里说「教材中未找到」
    说明检索到的片段确实没有相关内容。可以换个说法、加上具体章节名，或勾选「联网搜索」。
    公式显示成方块 / 乱码
    扫描件 OCR 认错符号的片段会标注「公式可能失真」；LaTeX 公式会自动渲染。
    Key 会被保存吗
    不会。只存在当前进程内存，关掉就没了；模型和端点会记住。
    支持哪些模型
    任何 OpenAI 兼容接口：DeepSeek、OpenAI、OpenRouter、Ollama、vLLM。
    换电脑后无法上传或找不到目录
    Windows 请先解压整个桌面安装包，保留 exe 同级的 _internal 文件夹，再运行 exe。不要在压缩包内启动或只复制 exe。书库下方可查看实际数据目录；源码版需安装 Python 和项目依赖后启动，不能直接双击 index.html。
    引用页码为什么对不上
    [1] 是来源编号，不是页码；PDF 页序从封面算起，可能不同于印刷页码。来源片段用于核对模型说法，引用编号正确不保证推理正确。
    还是搞不定
    在终端运行 studybuddy doctor，它会指出缺什么。

    模型设置

    Key 只保存在当前进程内存里，不写磁盘；模型和接口地址会被记住。

    填写服务商 API 控制台提供的信息，不是聊天网页地址。API 使用可能单独计费。保存设置只表示已填写，不代表网络和账户已验证。本地 Ollama 需先启动服务并下载对应模型。
